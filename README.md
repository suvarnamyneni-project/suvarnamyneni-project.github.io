# suvarnamyneni-project.github.io

Static portfolio for Suvarna Myneni. GitHub Pages serves this repository from the `main` branch with no build step. `.nojekyll` keeps Pages from running Jekyll.

The file there now is a placeholder framed so the laptop screen sits at about x 40–57 and y 32–50. Drop in the final 16:9 illustration under the same filename and retune that box if the screen shifts.
